Privacy policy - AI pomichnyk

Last updated: 29 October 2026

AI pomichnyk is a personal assistant in Telegram, set up individually for each user. This page explains what it does with Google user data.

What Google data it accesses

  • gmail.readonly - reads the user's email to tell her which letters need an answer or have a deadline.
  • gmail.send - sends an email from her account only after she explicitly asks for it. It never sends on its own.
  • calendar.events - creates and removes events for her appointments in Google Calendar.

It does not access contacts, Google Drive, documents or any other Google data.

How the data is used

Email and calendar data are used only to provide these features to the same user. The content of a message may be processed by an AI language model in order to summarise it or draft a reply for her.

Storage

The access token and the assistant's notes are stored on the server that runs this user's assistant, readable only by the service. Email content is not stored permanently; only short notes the user agrees to keep (for example a deadline) are saved.

Sharing

No data is sold, shared with third parties for their own purposes or used for advertising.

Google API Services User Data Policy

AI pomichnyk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. On request, all stored data of the user is deleted.

Datenschutzerklärung - AI pomichnyk

Stand: 29. Oktober 2026

AI pomichnyk ist ein persönlicher Assistent in Telegram, der für jede Nutzerin einzeln eingerichtet wird. Hier steht, was er mit Google-Nutzerdaten macht.

Auf welche Google-Daten er zugreift

  • gmail.readonly - liest die E-Mails der Nutzerin, um ihr zu sagen, welche Briefe eine Antwort brauchen oder eine Frist haben.
  • gmail.send - sendet eine E-Mail aus ihrem Konto nur, wenn sie es ausdrücklich verlangt. Er sendet nie von sich aus.
  • calendar.events - legt Termine im Google Kalender an und entfernt sie.

Auf Kontakte, Google Drive, Dokumente oder andere Google-Daten greift er nicht zu.

Wofür die Daten verwendet werden

E-Mail- und Kalenderdaten werden nur verwendet, um diese Funktionen für dieselbe Nutzerin bereitzustellen. Der Inhalt einer Nachricht kann von einem KI-Sprachmodell verarbeitet werden, um ihn zusammenzufassen oder eine Antwort für sie zu entwerfen.

Speicherung

Das Zugriffstoken und die Notizen des Assistenten liegen auf dem Server, auf dem der Assistent dieser Nutzerin läuft, und sind nur für den Dienst lesbar. E-Mail-Inhalte werden nicht dauerhaft gespeichert; gespeichert werden nur kurze Notizen, denen die Nutzerin zustimmt (zum Beispiel eine Frist).

Weitergabe

Daten werden nicht verkauft, nicht an Dritte für deren eigene Zwecke weitergegeben und nicht für Werbung genutzt.

Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen aus Google-APIs durch AI pomichnyk entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Auf Wunsch werden alle gespeicherten Daten der Nutzerin gelöscht.
